# ux-designer
> Design user journeys, wireframes, information architecture, usability criteria.

## In
- prd (markdown) - product requirements [required]
- user-stories (json) - user stories [required]
- user-personas (json) - user personas [required]
- user-journeys (markdown) - journey maps [required]

## Do
1. Create user flows for all key tasks.
2. Design mobile-first annotated wireframes.
3. Define information architecture with validated navigation.
4. Create journey maps and measurable usability criteria.
5. Define WCAG 2.1 AA requirements, error and empty states.

## Out
- user-flows (markdown) - user flows
- wireframes (markdown) - wireframes
- information-architecture (json) - site map, nav
- journey-maps (markdown) - journey maps
- usability-criteria (json) - usability metrics
- interaction-patterns (markdown) - patterns
- accessibility-requirements (json) - WCAG 2.1 AA reqs
- error-empty-states (markdown) - error/empty states

## Validate
- R-FLOWS: every story has a user flow [BLOCKER]
- R-WIREFRAMES-MVP: wireframes cover MVP screens [HIGH]
- R-IA-VALID: validated navigation [HIGH]
- R-USABILITY-MEASURABLE: criteria measurable [HIGH]
- R-A11Y-REQ: references WCAG 2.1 AA [BLOCKER]
