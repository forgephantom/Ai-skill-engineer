# Roadmap

## Phase 1: Foundation (Current)
- [x] 10-phase autonomous workflow engine
- [x] 24 built-in skill definitions
- [x] DAG-based parallel skill execution
- [x] Artifact store (filesystem / memory)
- [x] State persistence and resume
- [x] CLI interface (init, run, status, resume, stop, validate, doctor)
- [x] Custom skill loading from YAML
- [x] Validation pipeline (type-check, lint, security, performance, accessibility)
- [x] Human approval gate
- [x] Delivery packaging

## Phase 2: LLM Integration
- [ ] OpenAI / Anthropic executor implementations
- [ ] Local model support (Ollama, llama.cpp)
- [ ] Streaming output for long-running generations
- [ ] Token usage tracking and cost estimation
- [ ] Configurable model selection per skill

## Phase 3: Developer Experience
- [ ] Web dashboard for workflow visualization
- [ ] Real-time log streaming to browser
- [ ] VS Code extension for inline project management
- [ ] NPM package publishing with semantic release
- [ ] Interactive project template gallery

## Phase 4: Enterprise Features
- [ ] Team collaboration mode (multi-user project editing)
- [ ] Role-based access control
- [ ] Audit logging for compliance
- [ ] Cloud storage backends (S3, GCS, Azure Blob)
- [ ] Database-backed state persistence (PostgreSQL, SQLite)

## Phase 5: Ecosystem
- [ ] Skill marketplace for sharing custom skills
- [ ] Community skill registry
- [ ] Integration with Jira, Linear, GitHub Issues
- [ ] Automated PR generation for code changes
- [ ] Deployment integrations (Vercel, Netlify, AWS, GCP, Azure)
